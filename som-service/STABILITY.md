# Stability

This document lists the public surface of `som-service`: the command line,
the HTTP routes, the schema ids, the bundle format and the generated client.
`contract/public-surface.json` holds the same list in a form that a test reads.
`tests/it/stability.rs` fails when the code and the contract differ.

## Promise

Semantic versioning applies to everything in this document.
Nothing here breaks before 2.0.0.
A minor version may add an item; it does not remove or change one.
The crate `version` in `Cargo.toml` changes only when a person asks for it.

## Command line

The `som-service` binary has five subcommands:

- `serve`: runs the HTTP service. `--port` defaults to `8767`.
- `compile`: compiles a CNL file to a bundle. `--url` defaults to `http://127.0.0.1:8767`.
- `generate`: generates the client for a bundle. `--url` defaults to `http://127.0.0.1:8767`.
- `assemble`: renders the files of a bundle. `--url` defaults to `http://127.0.0.1:8767`.
- `identity`: prints the identity of the compiler.

## HTTP routes

| Method | Path | Smoke request | Smoke status | Other statuses |
|---|---|---|---|---|
| GET | `/health` | none | 200 | |
| GET | `/healthz` | none | 200 | |
| GET | `/readyz` | none | 200 | |
| GET | `/metrics` | none | 200 | |
| GET | `/openapi.json` | none | 200 | |
| GET | `/docs` | none | 200 | |
| POST | `/compile` | body `{` | 400 | 200, 413, 422 |
| POST | `/assemble` | body `{` | 400 | 200, 413, 422 |

`/health`, `/compile` and `/assemble` are the data routes and are listed in
the OpenAPI document. The other routes are the standard probe and
documentation routes of the core `service-http` crate.
A wrong method on `/compile` or `/assemble` gives 405. An unknown path gives 404.
Errors use the core `service-http` error envelope.

## Schema ids

- Formats: `som.cnl.service.v1`, `som.prompt-json.service.v1`, `som.prompt-json.service.v2`.
- Prompt versions: `som.prompt.service.v1`, `som.prompt.service.v2`.
- DSL versions: `som.dsl.service.v1`, `som.dsl.service.v2`.
- Targets: `rust-service-client.v1`.
- Bundle: `som.bundle.service.v1`.
- Compiler family: `som.service-compiler.v1`.

The ids of `formats`, `prompt_versions`, `dsl_versions` and `targets` are
returned by `GET /health`.

## Bundle format

A bundle is a JSON object of schema `som.bundle.service.v1` with the fields
`version`, `assets`, `prompt`, `dsl` and `digest`. `assets` names the
compiler family `som.service-compiler.v1`. `digest` is a hash of the other
fields.

## Generated client

The client generated by `som-service generate` exposes these public items:

- `Client`, with `Client::new(base_url)` and one method per operation: `task_status`, `task_create`, `queue_put` and `task_cancel`.
- `ClientError`, `ApiError` and the type aliases `ApiResult` and `ClientResult`.
- `TransportPolicy` and `PrivateTrust`.
- The per-operation error enums `TaskStatusError`, `TaskCreateError`, `QueuePutError` and `TaskCancelError`.
- The `models` module.

The tests do not check the generated client items.

## How the promise is checked

`contract/public-surface.json` lists the command names, the routes with their
smoke statuses, and the schema ids. `tests/it/stability.rs` checks that the
binary, the router, the OpenAPI document and the schema ids match that file,
and that this document names every item of it.

To change the public surface, change `contract/public-surface.json` and this
document in the same pull request.
